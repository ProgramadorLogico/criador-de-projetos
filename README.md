# Criador de projetos automatizado 

Olá, este é um projeto que estou desenvolvendo para me ajudar a criar projetos com mais facilidade
você também poderá utilizar este projeto e ele recerá atualizações conforme necessário para atualizar
ou melhorar recursos. Eu desenvolvi este projeto praticamente sozinho, mas precisei de ajuda pois
ainda estou aprendendo Shell Script, este arquivo não é perigoso, mesmo que agora parece que ele
realmente ficou perigoso pois falei que não é perigoso. 
Você pode utilizar e modificar este projeto há vontade de acordo com suas necessidades

[!NOTE]
> Este projeto é destinado para máquinas com Linux, mas talvez seja possível utilizar em máquinas Windows.

# Futuro do projeto

# Funcionamento resumido

O programa não altera quais quer arquivos que você possua, ele apenas cria o projeto, abaixo está a
de coisas que ele faz:

1. Pede o nome do projeto
2. Pede o nome das pastas e arquivos
3. Cria as pastas e arquivos

Abaixo estão os arquivos que o programa cria:

1. Arquivo principal
2. Arquivo de ferramentas
3. Arquivo de código
4. Arquivo README
5. LICENSE se for o seu caso

Lembrando, o programa foi construido para uso pessoal e criado especificamente para Java, caso você trabalhe
com C, C++, C#, Python, entre outros, este programa ainda não é para você, pelo menos não ainda, você pode
modificar para seu uso pessoal usando IAs ou não, este programa se ajusta conforme minhas necessidades e
organização pessoal
